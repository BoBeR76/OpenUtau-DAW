Cubase 15 用 OpenUtau DAW — ガイド
==================================

1. はじめに
   • Cubase で「OpenUtau DAW」プラグインを挿した Instrument トラックを追加します。
     OpenUtau がプラグインのウィンドウの中に開きます。
   • 歌手を選ぶ: OpenUtau のトラックのヘッダーにある歌手の欄をクリックします。
   • プラグインが一覧にない場合: Studio → VST Plug-in Manager → 再スキャン。

2. プラグインウィンドウ上部のバー
   • 丸印: 緑 — 音声の準備完了、黄 — レンダリング中、赤 — 問題あり
     （横に内容が表示されます。例:「トラック 2 に歌手がいません」）。
   • 「MIDI 同期」— 再生中に Cubase のノートを取り込みます（3 を参照）。
   • 「トラック:」— このプラグインが鳴らす OpenUtau のトラック。
   • ⚙ — 設定。

3. Cubase から OpenUtau へノートを送る
   方法 1 — ドラッグ＆ドロップ:
   • Cubase のプロジェクトウィンドウから MIDI パートを、OpenUtau の目的のトラックと小節へドラッグします。
   方法 2 — 再生中の同期:
   • 「OpenUtau DAW」トラックの MIDI パートにノートを書きます。
   • 「MIDI 同期」をオンにして、必要な部分を再生します。
   • ノートが OpenUtau に現れます。入力済みの歌詞はそのまま残ります。
   • 終わったら「MIDI 同期」をオフにします。
   • VOCALOID のように Cubase 内蔵のエディターでノートを書く機能は今後予定していますが、
     現時点ではまだできません。

4. OpenUtau から Cubase へノートを送る
   • OpenUtau のパートをつかんで、プラグインウィンドウの外へドラッグします。
   • Cubase の目的のトラックの空いている場所で離すと、MIDI パートができます。
   • Cubase が新しいトラックを作ってしまう場合: Edit → Preferences → MIDI → MIDI File →
     「Import Dropped File as Single Part」をオンにします。

5. テンポとトランスポート
   • テンポと拍子は Cubase から取り込まれます。
   • OpenUtau の再生・停止・先頭へ戻るボタンで Cubase を操作できます。
   • 曲の途中でテンポが変わる場合は、プロジェクトにブリッジを追加します（プロジェクトごとに 1 回）:
     a) オーディオトラックを作り、曲の長さいっぱいに任意のオーディオイベントを置いて
        ミュートします。
     b) そのイベントを選択 → Audio → Extensions →「OpenUtau DAW Bridge」。

6. 複数の声
   • Cubase で「OpenUtau DAW」トラックを追加すると、OpenUtau にも新しいトラックができます。
   • OpenUtau の「+」で、Cubase にも新しいトラックが追加されます。

7. キー操作（OpenUtau ウィンドウ内）
   • Space — 再生/停止、Home — 先頭へ、Ctrl+S — 保存。
   • キーが効かないときは、OpenUtau のウィンドウを一度クリックしてください。

8. 書き出し
   • 書き出しの前に、プラグインウィンドウの丸印が緑になるのを待ってください。

9. 保存と復元
   • ボーカルは Cubase のプロジェクトと一緒に自動で保存されます。
   • ファイル →「バックアップから復元」— 以前のバージョンのボーカルに戻せます。

10. Cubase のトラックに歌手の画像を表示する
   • ヘルプ →「Cubase 用の歌手画像」で画像のフォルダーが開きます。
   • Cubase でトラックの画像をダブルクリック → Import → 歌手を選びます。

11. 新しい音源
   • 音源のアーカイブ（.zip）を OpenUtau のウィンドウにドラッグします。
   • 音源が別のフォルダーにある場合（ポータブル版 OpenUtau など）: プラグインウィンドウで
     ツール → 設定 → ファイルの場所 →「シンガーの場所（追加）」→ そのフォルダーを指定します。
   • DiffSinger ではグラフィックボードを使います: ツール → 設定 → レンダリング →
     「機械学習の実行」。
