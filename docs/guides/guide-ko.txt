Cubase 15용 OpenUtau DAW — 사용 설명서
=====================================

1. 처음 시작하기
   • Cubase에서 “OpenUtau DAW” 플러그인이 들어간 인스트루먼트 트랙을 추가하세요.
     OpenUtau가 플러그인 창 안에서 바로 열립니다.
   • 가수 선택: OpenUtau 트랙 머리글의 가수를 클릭하세요.
   • 목록에 플러그인이 없으면: Studio → VST Plug-in Manager → 다시 검색.

2. 플러그인 창 위쪽의 막대
   • 점: 초록색 — 소리 준비 완료, 노란색 — 렌더링 중, 빨간색 — 문제가 있음
     (옆에 이유가 표시됩니다. 예: “트랙 2에 가수가 없습니다”).
   • “MIDI 동기화” — 재생하는 동안 Cubase의 음표를 가져옵니다(3번 참고).
   • “트랙:” — 이 플러그인이 재생하는 OpenUtau 트랙.
   • ⚙ — 설정.

3. CUBASE에서 OPENUTAU로 음표 보내기
   방법 1 — 끌어서 놓기:
   • Cubase 프로젝트 창의 MIDI 파트를 OpenUtau의 원하는 트랙과 마디로 끌어다 놓으세요.
   방법 2 — 재생하면서 동기화:
   • “OpenUtau DAW” 트랙의 MIDI 파트에 음표를 입력하세요.
   • “MIDI 동기화”를 켜고 필요한 구간을 재생하세요.
   • 음표가 OpenUtau에 나타나고, 이미 입력한 가사는 그대로 유지됩니다.
   • 끝나면 “MIDI 동기화”를 끄세요.
   • VOCALOID처럼 Cubase 자체 편집기에서 음표를 입력하는 기능은 앞으로 계획되어 있지만,
     아직은 불가능합니다.

4. OPENUTAU에서 CUBASE로 음표 보내기
   • OpenUtau에서 파트를 누른 채 플러그인 창 밖으로 끌어내세요.
   • 원하는 Cubase 트랙의 빈 곳에 놓으면 그 자리에 MIDI 파트가 생깁니다.
   • Cubase가 새 트랙을 만든다면: Edit → Preferences → MIDI → MIDI File →
     “Import Dropped File as Single Part”를 켜세요.

5. 템포와 재생 제어
   • OpenUtau는 Cubase의 템포와 박자를 따릅니다.
   • OpenUtau의 재생, 정지, “처음으로”가 Cubase를 제어합니다.
   • 곡 중간에 템포가 바뀐다면 프로젝트에 브리지를 추가하세요(프로젝트당 한 번):
     a) 오디오 트랙을 만들고, 곡 전체를 덮는 아무 오디오 이벤트나 올린 뒤
        음소거(Mute)하세요.
     b) 이벤트 선택 → Audio → Extensions → “OpenUtau DAW Bridge”.

6. 여러 목소리
   • Cubase에서 새 “OpenUtau DAW” 트랙을 만들면 OpenUtau에도 새 트랙이 생깁니다.
   • OpenUtau의 “+”는 Cubase에도 새 트랙을 추가합니다.

7. 단축키 (OpenUtau 창에서)
   • Space — 재생/정지, Home — 처음으로, Ctrl+S — 저장.
   • 키가 동작하지 않으면 먼저 OpenUtau 창을 클릭하세요.

8. 내보내기
   • 내보내기 전에 플러그인 창의 점이 초록색이 될 때까지 기다리세요.

9. 저장과 복원
   • 보컬은 Cubase 프로젝트와 함께 자동으로 저장됩니다.
   • 파일 → “백업에서 복원” — 보컬의 이전 버전으로 되돌아갑니다.

10. CUBASE 트랙의 가수 이미지
   • 도움말 → “Cubase용 가수 이미지”를 누르면 이미지가 있는 폴더가 열립니다.
   • Cubase에서 트랙 이미지를 더블클릭 → Import → 가수를 선택하세요.

11. 새 음원
   • 음원 압축 파일(.zip)을 OpenUtau 창으로 끌어다 놓으세요.
   • 음원이 다른 폴더에 있다면(포터블 OpenUtau 또는 직접 만든 폴더): 플러그인 창에서
     도구 → 환경 설정... → 경로 → “가수 폴더 확장” → 그 폴더를 선택하세요.
   • DiffSinger는 그래픽 카드를 사용하세요: 도구 → 환경 설정... → 렌더링 →
     “머신러닝 실행 장치”.
