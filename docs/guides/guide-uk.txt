OpenUtau DAW для Cubase 15 — інструкція
=======================================

1. ПЕРШИЙ ЗАПУСК
   • Додайте в Cubase Instrument-доріжку з плагіном «OpenUtau DAW».
     OpenUtau відкриється просто у вікні плагіна.
   • Виберіть співака: клацніть «Виберіть співака» в заголовку доріжки OpenUtau.
   • Якщо плагіна немає в списку: Studio → VST Plug-in Manager → пересканувати.

2. ПАНЕЛЬ УГОРІ ВІКНА ПЛАГІНА
   • Крапка: зелена — звук готовий; жовта — йде рендер; червона — щось не так
     (поруч написано, що саме, наприклад «немає співака в доріжки 2»).
   • «Синхр. MIDI» — перенесення нот із Cubase під час відтворення (див. п. 3).
   • «Доріжка:» — яку доріжку OpenUtau грає цей плагін.
   • ⚙ — налаштування.

3. НОТИ З CUBASE В OPENUTAU
   Спосіб 1 — перетягуванням:
   • Перетягніть MIDI-партію з вікна проєкту Cubase у вікно OpenUtau на потрібну доріжку й такт.
   Спосіб 2 — синхронізація під час відтворення:
   • Напишіть ноти в MIDI-партії на доріжці «OpenUtau DAW».
   • Увімкніть «Синхр. MIDI» і відтворіть потрібну ділянку.
   • Ноти з'являться в OpenUtau; склади, які ви вже ввели, зберігаються.
   • Закінчили — вимкніть «Синхр. MIDI».
   • Надалі планується використовувати вбудований редактор Cubase для запису нот,
     як у VOCALOID, але наразі такої можливості немає.

4. НОТИ З OPENUTAU В CUBASE
   • Затисніть партію в OpenUtau й витягніть її за край вікна плагіна.
   • Відпустіть на порожньому місці потрібної доріжки Cubase — там з'явиться MIDI-партія.
   • Якщо Cubase створює для неї нову доріжку: Edit → Preferences → MIDI → MIDI File →
     увімкніть «Import Dropped File as Single Part».

5. ТЕМП І ТРАНСПОРТ
   • Темп і розмір такту OpenUtau бере з Cubase.
   • Play, Stop і «на початок» в OpenUtau керують Cubase.
   • Якщо в пісні змінюється темп, додайте в проєкт міст (один раз на проєкт):
     а) створіть аудіодоріжку, покладіть на неї будь-яку аудіоподію на всю довжину пісні
        й заглушіть її (Mute);
     б) виділіть подію → Audio → Extensions → «OpenUtau DAW Bridge».

6. КІЛЬКА ГОЛОСІВ
   • Нова доріжка «OpenUtau DAW» у Cubase створює нову доріжку в OpenUtau.
   • «+» в OpenUtau додає нову доріжку й у Cubase.

7. КЛАВІШІ (у вікні OpenUtau)
   • Пробіл — Play/Stop, Home — на початок, Ctrl+S — зберегти.
   • Якщо клавіша не спрацьовує — клацніть по вікну OpenUtau.

8. ЕКСПОРТ
   • Перед експортом дочекайтеся зеленої крапки у вікні плагіна.

9. ЗБЕРЕЖЕННЯ Й ВІДНОВЛЕННЯ
   • Вокал зберігається сам разом із проєктом Cubase.
   • Файл → «Відновити з резервної копії» — повернути одну з попередніх версій вокалу.

10. ЗОБРАЖЕННЯ СПІВАКА НА ДОРІЖЦІ CUBASE
   • Довідка → «Зображення співаків для Cubase» відкриє папку із зображеннями.
   • У Cubase двічі клацніть по зображенню доріжки → Import → виберіть співака.

11. НОВІ ГОЛОСИ
   • Перетягніть архів голосового банку (.zip) у вікно OpenUtau.
   • Якщо голоси лежать в іншій папці (портативний OpenUtau або своя папка): у вікні плагіна
     Інструменти → Налаштування → Шляхи → «Додатковий Шлях Співаків» → укажіть цю папку.
   • Для DiffSinger увімкніть відеокарту: Інструменти → Налаштування → Рендер →
     «Пристрій для Виконання Машиного Навчання».
